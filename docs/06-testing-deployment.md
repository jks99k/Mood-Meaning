# 06. 테스트, 배포 및 완료 검증

## 1. 로컬 실행 준비
1. Node.js LTS를 설치한다.
2. 저장소에서 `npm install`을 실행한다.
3. `.env.example`을 참고해 로컬 환경변수를 준비한다. 실제 키는 저장소에 넣지 않는다.
4. Vercel CLI 개발 서버 또는 프로젝트에서 정한 로컬 실행 방법으로 정적 페이지와 `/api/analyze`를 함께 실행한다.
5. OpenAI와 Supabase 키가 없으면 외부 연동 테스트는 완료할 수 없다. 이 경우 UI/입력 검증만 별도로 테스트하고 연동 테스트는 미완료로 기록한다.

## 2. 필수 테스트 체크리스트

### 입력
- [ ] 공백만 입력하면 분석 요청이 발생하지 않는다.
- [ ] 빈 입력에 구체적인 한국어 오류가 표시된다.
- [ ] 2,000자 입력이 허용된다.
- [ ] 2,001자 입력이 클라이언트와 서버에서 거부된다.
- [ ] 문자열이 아닌 `text` 요청이 서버에서 거부된다.

### AI 및 API
- [ ] 긍정 문장에 `positive`가 반환되고 UI에 “긍정”으로 표시된다.
- [ ] 부정 문장에 `negative`가 반환되고 UI에 “부정”으로 표시된다.
- [ ] 중립 문장에 `neutral`이 반환되고 UI에 “중립”으로 표시된다.
- [ ] confidence가 0~100 정수로 표시된다.
- [ ] 분석 이유가 표시된다.
- [ ] 잘못된 AI JSON/enum/범위 값이 성공으로 표시되지 않는다.
- [ ] OpenAI 키 누락/호출 실패 시 안전한 오류가 표시된다.
- [ ] POST 이외 메서드는 거부된다.

### 저장
- [ ] 성공 분석 결과가 Supabase에 저장된다.
- [ ] 저장된 행에 입력 문장, 감정, 신뢰도, 이유, 모델, 생성 시각이 포함된다.
- [ ] DB 연결 실패 시 분석 결과는 화면에 표시되고 저장 실패 안내가 나타난다.
- [ ] 비밀 키가 브라우저 소스/네트워크 응답에 노출되지 않는다.

### UI/접근성
- [ ] 360px, 768px, 1024px, 1440px에서 레이아웃을 확인한다.
- [ ] 360px에서 가로 스크롤이 없다.
- [ ] 키보드만으로 입력하고 분석할 수 있다.
- [ ] 포커스 표시가 보인다.
- [ ] 결과와 오류 상태가 보조기술에 전달된다.
- [ ] 감정이 색상만이 아니라 텍스트로 구분된다.
- [ ] 로딩 중 중복 제출이 불가능하다.

## 3. Supabase 설정
- Supabase 프로젝트를 생성한다.
- SQL Editor에서 `supabase/schema.sql`을 실행한다.
- 테이블 생성 여부와 컬럼 타입을 확인한다.
- 서버에서만 service role 키를 사용한다.
- 공개 브라우저 접근은 제공하지 않는다. RLS를 활성화하고 클라이언트 직접 쓰기를 허용하지 않는다.
- 보존 기간은 별도 합의 전까지 임의 설정하지 않는다.

## 4. Vercel 배포
1. Git 저장소를 Vercel에 연결한다.
2. 프로젝트의 Node.js 런타임 및 정적 파일 설정을 확인한다.
3. `OPENAI_API_KEY`, `OPENAI_MODEL`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`를 Vercel의 환경변수에 등록한다.
4. Preview 환경과 Production 환경에 필요한 값을 각각 설정한다.
5. 배포 후 실제 도메인에서 입력/분석/저장 흐름을 점검한다.
6. 환경변수 변경 후에는 새 배포가 필요한지 확인한다.

## 5. 배포 완료 기준
- [ ] Vercel 배포가 성공했다.
- [ ] 첫 화면과 정적 자산이 정상 로드된다.
- [ ] `/api/analyze`가 정상 요청을 처리한다.
- [ ] OpenAI 응답이 결과 UI에 표시된다.
- [ ] Supabase 저장이 확인된다.
- [ ] 오류 케이스가 적절히 표시된다.
- [ ] 브라우저에서 비밀 키를 찾을 수 없다.
- [ ] 모바일과 데스크톱 레이아웃이 정상이다.

## 6. 최종 보고 형식
에이전트는 다음을 사실대로 보고한다.
- 구현 완료/미완료 기능
- 실행한 명령과 테스트 결과
- 테스트하지 못한 항목 및 이유
- Vercel/Supabase/OpenAI에서 사용자가 직접 해야 할 설정
- 보안/개인정보 관련 주의사항
- 알려진 제한사항

“코드 작성 완료”와 “실서비스 검증 완료”를 같은 의미로 사용하지 않는다.
